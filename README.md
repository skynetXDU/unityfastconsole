## unity快速控制台

主要目的是方便一次性代码的执行, 不用再临时写cs文件

### 安装
在unity 包管理器中，输入https://github.com/skynetXDU/unityfastconsole.git进行安装；

### 特点
1. 便捷执行一次性代码；
2. 代码高亮；
3. 代码补全；
4. 自动缩进控制；
5. 括号引号的自动补全；
6. 可调字体、行距、可开关代码高亮

### 使用
安装并编译后，打开工具栏的"Tools/快速控制台"即可开始编写代码；

### 注意事项
第一次开始编辑代码可能会比较慢，后面就好了；
代码高亮比较耗时，当代码行数很多时建议关掉实时高亮；
不建议在本控制台编辑大量代码；
